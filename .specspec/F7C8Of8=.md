# One parametric model is the source of geometry, checks and pictures

The device exists as a CadQuery model in Python. Every dimension is a named value in one parameter file with a reference to the research note that justifies it. Values that still have to be measured on delivered parts are marked.

Printable files, the verification report, every rendering and the bill of materials are generated from this model by one command, so they cannot contradict each other. Purchased components are modelled as simple, recognisable dummy bodies with faithful envelopes.

Origin: agent conclusion.
