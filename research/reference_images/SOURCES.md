# Poké Ball reference images — sources

All files were downloaded on **2026-11-17** with `curl` and a browser User-Agent. They are third-party,
mostly copyrighted images (© Nintendo / Creatures / GAME FREAK / The Pokémon Company, The Wand Company,
Jazwares, or the fan authors named below) kept here only as private measurement references — do not
redistribute them with the project. They are untrusted downloads: the scripts only decode them with Pillow.

`F*` = front-facing views that were measured, `S*` = side / three-quarter / opened views used for depth,
hinge and seam information. Results: `../03_pokeball_proportions.md`.

## Not obtained

* Bulbapedia / archives.bulbagarden.net (Cloudflare challenge for curl and WebFetch) — the Sugimori artwork comes from the mirrors above.
* Thingiverse renders (API needs a token). Printables and Sketchfab were used for fan models instead.
* A straight-on photo of a **closed** Jazwares / Tomy ball, and any published diameter for them.
* A dead-on side profile (button exactly on the silhouette) of any official replica; depth values come from ~44° views.

## Scripts and outputs in this folder

Run from the repo root, isolated and without writing byte-code next to the downloads:

```sh
uv run python -I -B research/reference_images/measure_front_views.py   # -> measurements_front.json, overlays/F*_overlay.png
uv run python -I -B research/reference_images/measure_side_views.py    # -> measurements_side.json,  overlays/S01_overlay.png, S03_overlay.png
uv run python -I -B research/reference_images/measure_colors.py        # -> measurements_colors.json
uv run python -I -B research/reference_images/measure_summary.py       # -> table + statistics (stdout), measurements_summary.json
uv run python -I -B research/reference_images/measure_probe.py line IMG metric x0 y0 x1 y1   # exploration helper
```

* `measure_common.py` — image loading, edge finding along a line, circle / ellipse fits, overlay drawing.
* `overlays/*.png` — each measured image with the fitted silhouette (cyan), ring outer edge (yellow), white-disc
  edge (green), button edge (magenta) and band-thickness probes (blue) drawn in. They were all checked by eye.
