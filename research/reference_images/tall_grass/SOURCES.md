# Tall grass reference images — sources

All files were downloaded on **2026-11-17** with `curl` and a generic browser User-Agent. They are third-party,
copyrighted images (© Nintendo / Creatures / GAME FREAK / The Pokémon Company, Niantic for the Pokémon GO asset;
hosted by the fan wikis and sites named below) kept here **only as private visual and colour references** — do not
redistribute them with the project. They are untrusted downloads: they were only decoded with Pillow
(`uv run python -I <script> <image>`), nothing in them was executed. The files are stored unmodified.

Results (tuft shapes, proportions, measured colours, recommendation): `../../10_grass_look_and_small_parts.md`, Part A.

## How the colours were measured

Scripts are not kept in the repository (they were run from a temporary folder). Method: Pillow decodes the image;
pixels inside hand-picked boxes are kept if their HSV hue is 60–190° (yellow-green to teal), saturation ≥ 0.15 and
value ≥ 0.06; for pixel art the exact palette with pixel counts is listed instead; for everything else a k-means
clustering (k = 3, deterministic start at luminance quantiles) gives a dark, a middle and a light cluster. Boxes
(x0, y0, x1, y1 in pixels): G03 60,100,200,170 · G04 70,60,160,200 and 215,60,320,200 · G05 whole image, alpha ≥ 200 ·
G06 130,310,530,395 and 340,255,540,300 · G07 300,500,560,590 and 820,500,1250,580 · G09 0,330,798,443 (hue 60–150°,
saturation ≥ 0.25, to keep the turquoise sky out) · G10 60,380,675,525 (hue 65–185°, to keep the yellow costume out).
